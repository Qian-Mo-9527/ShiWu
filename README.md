# 拾物：本地二手物品交易程序源码

本压缩包仅包含成品源码、必要界面资源与编译脚本，不含 EXE、本地数据库、测试文件、测试数据或检查记录。程序核心使用 C 语言、Win32 和 SQLite，运行时无需联网。

## 首次运行

源码中的预置账号、密码、商品和成交记录已全部移除。编译后的程序首次运行时自动创建 `data/market.db` 与 `data/images/`，数据库中没有用户、商品或订单。

前端先注册账号，再登录使用。后台无需登录，可直接新增用户和商品。后台新增用户没有预置头像，界面默认使用昵称首字作为占位头像，可自行选择 JPG / PNG 图片。

登录页保留台灯、相机插画作为界面装饰，未把它们写入商品数据库。

## 文件结构

- `src/frontend.c`：用户前端与页面交互。
- `src/backend.c`：独立本地数据管理界面。
- `src/store.c`、`src/store.h`：数据库、账号、钱包、商品与成交规则。
- `src/ui.c`、`src/ui.h`：控件、绘制、图片与数字输入处理。
- `src/*.rc`、`src/app.manifest`：Windows 图标与程序清单。
- `assets/`：编译和界面所需的图标及两张装饰插画。
- `vendor/sqlite3.c`、`vendor/sqlite3.h`、`vendor/NOTICE.txt`：SQLite 源码及说明。
- `build.cmd`、`build.ps1`：构建脚本。
- `SHA256SUMS.txt`：源码包内文件的 SHA256（不包含该清单自身）。

## 编译方法

适用于 Windows 10 / 11 的 64 位系统。安装 Visual Studio 或 Visual Studio Build Tools，并安装“使用 C++ 的桌面开发”和 Windows SDK；其中提供 C 编译器。无需安装 Python 或单独的 SQLite。

解压后打开 `拾物_成品源码` 文件夹，双击 `build.cmd`；也可以在该文件夹的 PowerShell 中运行：

```powershell
.\build.ps1
```

如本机 PowerShell 执行策略阻止脚本，可直接双击 `build.cmd` 编译。

编译成功后，文件夹内会生成 `二手交易.exe` 与 `本地数据管理.exe`。两个程序共享同目录下的本地数据，移动时请同时保留 `assets` 和运行时生成的 `data` 文件夹。

## 程序功能

- 注册、登录仅需账号和密码，密码框支持显示与隐藏。
- 前端包含交易、上架、我的；交易页不显示自己上架、已售出或已下架的商品。
- 商品名称、介绍、价格、图片必填，每件商品一张 JPG / PNG 图片。
- 我的包含个人资料、头像、钱包、已购买、已上架和退出登录；可修改昵称、简介、头像和密码。
- 充值为本地演示操作，输入金额后加入钱包；购买成功将商品金额转入卖家钱包，并生成成交记录。
- 金额输入最多两位小数，单笔金额及钱包余额上限为 9999999.99 元；余额不足提示“余额不足，请充值”。
- 用户下架后在已上架列表标注“商品已下架”；后台下架标注“商品已被管理员下架”；已成交商品不可下架或改回未售。
- 后台支持用户和商品的增删改查；删除用户时删除其商品，历史成交快照保留。

新创建的数据库为空；使用过程中自行注册、充值或上架后产生的数据属于正常本地业务数据，退出后仍会保存。
